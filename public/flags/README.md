# Флаги стран

Источник: [lipis/flag-icons](https://github.com/lipis/flag-icons) v7.5.0, лицензия MIT
(текст — в файле `LICENSE` рядом).

Файл выбирается по коду ISO 3166-1 alpha-2 из поля `code` страны:
`/flags/4x3/{code}.svg` и `/flags/1x1/{code}.svg`.

Флаги лежат статикой, а не в медиатеке Payload: их 243, они не меняются, и в
списке загрузок они бы похоронили всё остальное. Если для страны нужен свой
файл — загрузите его в поле «Флаг», оно перебивает подстановку по коду.

Обновление: `npm pack flag-icons@<версия>` и распаковать каталоги `flags/1x1`
и `flags/4x3` сюда же.
